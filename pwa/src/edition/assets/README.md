# Classic 911 sketch

`porsche-911-sketch.png` is an original designer-style interpretation of the
classic Porsche 911 reference photograph supplied by the user on 30 October
2026. It preserves the front three-quarter perspective and removes the scene
and registration lettering. Generated with the built-in imagegen tool, then
refined to transparent pen strokes. The app extracts ink luminance and applies
its own theme colour with an SVG filter, keeping the wheel highlights open.
The reference photograph itself is not included in the app.
